From the earlier release registers. Before the Data Uses Register began in July 2021, NHS Digital published a release register, quarterly and then monthly, listing the data it had released in each period. It names each agreement version that received data, and from 2016 its purpose. It gives no titles, terms or controllers, and lists a version only in periods when data was released under it.
