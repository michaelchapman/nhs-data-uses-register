The register

NHS England publishes the Data Uses Register monthly as a spreadsheet workbook, with agreements, datasets and file releases on three sheets. It is the authoritative source. The {{ meta.edition|edition }} edition, which this site was built from, is {{ meta.source_file }}, listed on the Data Uses Register page.

One row per agreement in the {{ meta.edition|edition }} edition, with what this site adds to the workbook: the organisation page each applicant and data controller is listed under, after merged spellings and NHS reorganisations; its sector; whether the agreement is in term; the bases on which confidential data may flow and whether patient opt-outs were applied; and each dataset under one name. The purpose text is left out, as are agreements no longer in the register: the workbook holds the first, and the second are in no count on this site.

Every edition, as this site holds it

The site is built from a store of what every edition held since {{ meta.editions[0].edition|edition if meta.editions else "the first edition ingested" }}: one JSON file per agreement, with every version and each state it was published in, and one per agreement for its file releases. It is in the site's code repository, with the code that reads the workbooks and builds these pages, so you can see how each page is made and build it yourself.

meta.json gives the edition, source, retrieval date and headline counts for the current build.
