About this site

NHS England publishes the Data Uses Register as a monthly spreadsheet. It is complete and authoritative, and it is also a {{ stats.agreement_versions|commas }}-row, 29 MB workbook with three sheets you have to join by hand. This site is the same data, rearranged so a person can read it.

What the register covers

The Data Uses Register records data sharing agreements under which NHS England has released data to organisations outside NHS England, through the Data Access Request Service (DARS). For each agreement it gives the applicant organisation, the data controllers, the term, the stated purpose and expected benefits, the datasets approved, and the individual files released.

It does not cover NHS England's internal uses of data (a separate internal register), the Data Sharing Framework Contracts that sit above individual agreements, or releases made by other organisations. Links to those are on the official register page.

What this site changes

  • One page per agreement, not one row per renewal. The register lists every version of an agreement separately — {{ stats.agreement_versions|commas }} rows for {{ stats.agreements|commas }} agreements. Here versions are grouped under the agreement, with the history kept underneath.
  • The three sheets are joined. Datasets and file releases are shown on the agreement they belong to, rather than in separate sheets keyed on a reference number.
  • Free text is readable. Purpose, processing activities, expected outputs and benefits are laid out as prose instead of a single overflowing cell.
  • Organisations and datasets get their own pages, so you can start from "what has this university received" or "who gets Hospital Episode Statistics".
  • Everything has a stable URL you can link to or cite.
  • Month-on-month changes are tracked on the what changed page.
  • Flat CSVs are available on the download page for anyone who wants to do their own analysis.

Accessibility

Pages are plain semantic HTML: one h1 per page, real table headers with scope, visible focus outlines, a skip link, and text that reflows to 400% zoom. Filtering is a progressive enhancement — every table is fully present in the HTML, so the site works with JavaScript disabled and with a screen reader. There are no cookies, no analytics and no third-party requests.

If something here is hard to use, please open an issue.

Caveats

  • This is a mirror, not the source. Transformation bugs are possible. For anything consequential, check the original workbook.
  • The register describes agreements, not outcomes. "Expected benefits" is what an applicant said they intended, not an audited result.
  • An agreement is not the same as an active data flow. The files-released figures give a better sense of what actually moved.
  • Counts change between editions as NHS England corrects entries and retires expired agreements, so figures here will not always reconcile with earlier published analyses.
  • File releases are summarised by dataset rather than listed file by file. The full file-level rows are in the source workbook.

How it stays up to date

A GitHub Actions workflow runs monthly. It reads the official register page, finds the current workbook link, downloads it, rebuilds every page, and deploys. It also records a fingerprint of each agreement version so the next run can report what changed. The whole pipeline is in the repository — corrections and pull requests welcome.
