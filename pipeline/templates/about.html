About this site

NHS England publishes the Data Uses Register as a monthly spreadsheet. It is the authoritative source but it is also a {{ stats.agreement_versions|commas }}-row, 29 MB workbook with information across three sheets. This site is the same data, rearranged for easier access.

What the register covers

The Data Uses Register records the data sharing agreements, made through the Data Access Request Service (DARS), under which organisations outside NHS England may use data it holds. For each agreement it gives the applicant organisation, the data controllers, the term, the stated purpose and expected benefits, the datasets approved, and individual files released externally by DARS.

It does not cover NHS England's internal uses of data (a separate internal register), the Data Sharing Framework Contracts that sit above individual agreements, or releases made through other routes. Links to those are on the official register page.

If you don't want your data used

Most people in England can choose to stop their confidential patient information being used for research and planning, through the National Data Opt-out. It is run by the NHS, not by this site. The opt-out does not apply to every use: data that is anonymised, or shared with your consent, or where the law requires it, is not covered. Where the register records whether opt-outs were applied to a file release, this site shows it on the agreement page.

What this site changes

  • One page per agreement, not one row per renewal. The register lists every version of an agreement separately — {{ stats.agreement_versions|commas }} rows for {{ stats.agreements|commas }} agreements. Here versions are grouped under the agreement, with the history kept underneath.
  • The three sheets are joined. Datasets and file releases are shown on the agreement they belong to, rather than in separate sheets keyed on a reference number.
  • Free text is readable. Purpose, processing activities, expected outputs and benefits are laid out as prose instead of a single overflowing cell.
  • NHS organisations are followed through reorganisations. Using the NHS Organisation Data Service (ODS), the site recognises when the register renames an NHS organisation or names its successor, such as an integrated care board taking over from a clinical commissioning group in July 2022. Those are shown as renames and successions rather than counted as changes to an agreement, and each integrated care board has one page, listing the sub-ICB locations the register also names it by. Names are shown without their ODS codes, except where a code explains which organisation continued which.
  • Organisations are grouped into sectors. The register gives each applicant one of about 30 organisation types, and commercial applicants alone are spread across Commercial, Supplier, Consultancy, SME and others. The Sector filter groups the types into six: NHS, local government, central government and public bodies, universities, charities and not-for-profits, and companies. Some organisations are placed by hand, because their type does not say what they are: the register files universities, charities, public bodies and companies alike as "Research". Each of those organisation pages gives the reason, and the full list is in data/organisation-sectors.json. The register's own type is still shown and can still be filtered on.
  • Organisations and datasets get their own pages, so you can start from "what agreements does this university hold" or "which agreements name Hospital Episode Statistics".
  • Everything has a stable URL you can link to or cite. An agreement that leaves the register keeps its page, marked as no longer in the register and showing what the register last said, but it is not counted in this site's figures.
  • Month-on-month changes are tracked on the what changed page.
  • It publishes pages, not data files. For analysis, get the data from the register itself, or from this site's archive of every edition.

Caveats

  • This is a mirror, not the source. Transformation bugs are possible. For anything consequential, check the original workbook.
  • A few published records are left out because they are not data sharing, such as a test record the register published in error. Each is listed, with the reason, in data/excluded-agreements.json.
  • The register describes agreements, not outcomes. "Expected benefits" is what an applicant said they intended, not an audited result.
  • An agreement is not the same as an active data flow. Some agreements may simply allow organisations to continue to use data they already hold.
  • Many listed agreements have ended. The register keeps an agreement after its term has passed, so {{ (stats.agreements - stats.active_agreements)|commas }} of the {{ stats.agreements|commas }} agreements in the {{ meta.edition|edition }} edition are marked "Expired" here. An agreement is counted as in term if its latest version had not ended by the first day of the edition's month.
  • Counts change between editions as NHS England corrects entries and retires expired agreements, so figures here will not always reconcile with earlier published analyses.
  • Organisation names are re-capitalised for reading. The register writes most of them in capitals, so this site shows "UNIVERSITY OF OXFORD" as "University of Oxford". It is a display change only, done by rule, so an unusual name or an acronym it doesn't know can come out wrong ("Ims Health"). A page whose name was changed says how the register writes it.
  • File releases are summarised by dataset rather than listed file by file. The full file-level rows are in the source workbook. The files-released figures give a view of files released. They don't cover access granted in NHS England's own systems, such as its Secure Data Environment and predecessors.

How it stays up to date

By hand, and not automatically. This site shows the {{ meta.edition|edition }} edition, added on {{ meta.retrieved[:10]|date }}. NHS England publishes a new one each month, but it won't appear here until shortly afterwards — so if a newer edition is out, this site does not have it yet. The official register page always has the current workbook, and the release archive has previous ones.
