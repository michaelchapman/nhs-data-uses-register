OpenSAFELY projects

OpenSAFELY is a way of analysing NHS health records without copying them out of where they are stored. Researchers write code, the code is run against the records, and only aggregated results, as tables and graphs, come back. The NHS England OpenSAFELY service is funded by NHS England, which decides which projects are approved.

No file of data is released to an OpenSAFELY project, so none of these projects is in the Data Uses Register. They are listed here from OpenSAFELY's own list, and are not counted in this site's figures for agreements or files released.

What this list shows

  • Only the facts of each project: its number, title, organisation, type and start date. What a project is doing is on its OpenSAFELY page, and its code and results are on the OpenSAFELY jobs site. The descriptions are not copied here: opensafely.org is © University of Oxford, and may be copied only for non-commercial research and study.
  • Projects up to number 205 were limited to COVID-19, which was all the government's Directions then allowed. Directions issued in June 2025 allow research on any health topic.
  • Start dates are given only for recent projects. OpenSAFELY's list gives none for the earlier ones.
  • Organisations are as OpenSAFELY names them, often several to a project. Each links to this site's page for it where there is one, which also lists its OpenSAFELY projects.
